# dp-cj 安装与使用说明

## 这个 Skill 做什么

`dp-cj` 只做短视频文案提取和飞书 Base 入库：

1. 先确认视频要放入哪张分类表。
2. 提取视频文案、标题、封面、时长和互动数据。
3. 写入用户确认的飞书表。

不负责改写、洗稿、润色、选题策划或发布。

## 一、安装

将 `dp-cj` 文件夹放到 WorkBuddy 的 Skill 目录：

```text
你的项目/.workbuddy/skills/dp-cj/
```

也可以放到用户级目录：

```text
C:\Users\你的用户名\.workbuddy\skills\dp-cj\
```

安装后如果输入 `/dp-cj` 没反应，请新建会话或重启 WorkBuddy，让程序重新加载 Skill 列表。

## 二、首次配置

在 `dp-cj` 目录复制配置：

```powershell
Copy-Item config.example.json config.json
```

一般只需要修改：

| 配置项 | 填什么 |
|---|---|
| `workspace_root` | 你的本地工作区绝对路径 |
| `python_executable` | 可用的 Python；一般填 `python` |
| `extraction.transcribe_script` | 本地 `transcribe.py` 路径；没有本地 ASR 可留空 |

飞书 Base 和七张表已经配置为：

https://my.feishu.cn/base/AjdAbLBMEazYJRsX6u7cKUXjnBM?from=from_copylink

初始化并检查：

```powershell
python scripts/setup_workspace.py --config config.json
python scripts/doctor.py --config config.json --live
```

看到“核心配置通过”即可使用。

## 三、更新

安装完成后输入：

```text
/dp-cj-update
```

WorkBuddy 会自动读取 GitHub 最新 Release、下载压缩包、校验 SHA-256、备份当前 Skill 并更新。保留本地路径和自定义配置；官方 Base 缺少的新分类、行业映射会增量补入，原配置会备份。本地工作区内容保留。

## 四、怎么用

### 方式 1：提取抖音链接

发送：

```text
/dp-cj https://v.douyin.com/xxxxxxx/
```

也可以直接发完整分享文案。

Skill 会先问：

```text
请确认这条链接要放入哪张表：
1. 工厂实体店
2. 情感(泛流量)
3. 自媒体+AI
4. 搞钱(干货)
5. 人设
6. 营销
7. 情感共鸣型（泛流量）
```

回复表名或编号，例如：

```text
2
```

确认后 Skill 才开始提取并入库。完成后会报告标题、分类表、时长、互动数据、写入动作和 Base 结果。

### 方式 2：提取本地视频或音频

发送：

```text
/dp-cj 提取本地文件 E:\视频\测试.mp4，作者：测试作者
```

同样先确认分类表，确认后开始转写。

本地文件没有原视频链接时，请补充链接；没有链接会影响重复入库判断。

### 方式 3：已经有一份文案

发送：

```text
/dp-cj 我已经拿到文案，准备入库
```

然后提供：
- 目标分类
- 标题
- 原视频链接
- 文案全文
- 发布日期、时长和互动数据（如有）

## 五、会写入哪些字段

| 字段 | 说明 |
|---|---|
| 标题 | 视频标题，自动去掉话题标签 |
| 文案全文 | 提取到的口播全文 |
| 开头+金句 | 原文开头和原文金句 |
| 选题 | 视频核心主题 |
| 链接 | 原视频链接 |
| 平台 | 抖音 / 视频号 / 小红书 |
| 发布日期 | `YYYY-MM-DD` |
| 视频时长 | `mm:ss` |
| 点赞数 | 数字 |
| 评论数 | 数字 |
| 收藏数 | 数字 |
| 分享数 | 数字 |
| 行业 | 按全文主营业务归到标准单选项；火锅店、卤味店、面馆归餐饮；不确定时保留待补原因 |
| 文案类型 | 与确认的分类一致；没有该字段的表自动跳过 |
| 封面 | 自动下载并上传作品实际展示封面（按 dynamic_cover → cover_original_scale 取图） |
| 标题截图 / 赞藏截图 | 只有提供文件或 URL 时上传 |

## 六、重复链接怎么处理

同一个链接再次入库时，Skill 会按“链接”查重：

- 已存在：更新原记录。
- 不存在：创建新记录。

不会因为重复发送同一链接而新增重复行。

## 七、常见问题

### 1. 输入 /dp-cj 没反应

- 确认目录名是 `dp-cj`。
- 确认 `SKILL.md` 中是 `name: dp-cj`。
- 新建会话或重启 WorkBuddy。

### 2. 提示 config.json 不存在

执行：

```powershell
Copy-Item config.example.json config.json
```

然后填写本地路径，再运行 doctor。

### 3. 提取失败或转写质量差

先运行：

```powershell
python scripts/doctor.py --config config.json --live
```

如果在线链接失败，可让 Skill 使用有头浏览器重试。OCR 只作为最后兜底，文字可能有同音字误差。

### 4. 封面不完整

Skill 会按 dynamic_cover → cover_original_scale 的顺序取作品实际展示封面（不自动使用 origin_cover 随机截帧或横裁 poster 兜底；下载后核对真实展示内容）。如果取到的封面仍不理想，请提供一张封面图片或截图。

### 5. 分类选错了

必须在提取前回复正确的表名或编号。如果已经写入错误分类，请明确告诉 Skill“这条链接分类选错了”，再由用户确认如何移动或删除。
